# مدیریت شخصی وصله — اپ iOS

اپ iOS نرم‌افزار مدیریت شخصی وصله، با SwiftUI برای iOS 17 به بالا.
نام کاری پروژه «Vasleh Personal» است؛ این نام قابل تغییر است و در تنظیمات پروژه
(`PRODUCT_NAME` و نام هدف) عوض می‌شود.

> هشدار صادقانه: این سورس روی مک و Xcode کامپایل نشده است، چون این محیط
> لینوکس است و Xcode ندارد. پیش از نصب روی آیفون، پروژه را در Xcode باز کن
> و یک بار بیلد بگیر.

## نیازمندی‌ها

- مک با Xcode 15 یا بالاتر، Swift 5.9
- iOS 17 یا بالاتر روی دستگاه یا شبیه‌ساز
- برای نصب روی آیفون واقعی: حساب توسعه‌دهندهٔ اپل (Apple Developer)؛
  روی شبیه‌ساز حساب توسعه‌دهنده لازم نیست
- بدون هیچ وابستگی خارجی: فقط SwiftUI و Foundation و Security

## باز کردن در Xcode

روش اول: روی `VaslehPersonal.xcodeproj` دابل‌کلیک کن.

روش دوم (اگر پروژه باز نشد): در Xcode یک پروژهٔ App تازه بساز، همهٔ
فایل‌های پوشهٔ `VaslehPersonal` را به پروژه اضافه کن و `MainTabView` و
`LoginView` را از همان فایل‌ها بگیر؛ نقطهٔ ورود `VaslehPersonalApp` است.

## نشانی API

نشانی پایه در یک جا تعریف شده است: `APIConfig.baseURL` در
`Services/APIClient.swift` که الان `https://atroweb.ir` است. برای عوض کردن
سرور فقط همان یک خط را عوض کن. همهٔ endpointها زیر `/api/v1/` هستند و
جزئیاتشان در `API-CONTRACT.md` آمده است.

## جابه‌جایی بین دادهٔ نمونه و API واقعی

یک پرچم برای این کار هست: `useMockAPI` در `AppState`.

- پیش‌فرض روشن است؛ اپ با دادهٔ نمونه اجرا می‌شود و همهٔ صفحه‌ها، تیک زدن،
  افزودن و تایمر کار می‌کنند، بدون نیاز به سرور. در حالت نمونه، هیچ پیامکی
  واقعاً ارسال نمی‌شود و هر کد ۵ رقمی پذیرفته می‌شود.
- برای API واقعی، در خود اپ به تنظیمات برو و «استفاده از دادهٔ نمونه» را
  خاموش کن، یا مقدار پیش‌فرض `useMockAPI` را در `AppState` عوض کن.

توجه: endpointهای موبایل هنوز روی سرور وصله ساخته نشده‌اند (قرارداد است،
نه پیاده‌سازی)؛ تا وقتی ساخته نشوند، حالت API واقعی خطا می‌دهد.

## صفحه‌ها

- ورود: شمارهٔ موبایل + کد تایید ۵ رقمی پیامکی (دو مرحله، با تایمر ارسال
  دوباره و ویرایش شماره)، حالت بارگذاری، نمایش خطا، ذخیرهٔ توکن
  در Keychain و بازیابی نشست با باز شدن دوبارهٔ اپ.
- امروز: سلام با نام کاربر، تاریخ جلالی، درصد پیشرفت روز، تایمر پومودورو
  و پنج کار اول امروز.
- کارها: تیک زدن، افزودن و حذف.
- تقویم: نوار هفت روز و رویدادهای روز انتخاب‌شده.
- یادداشت‌ها: فهرست و افزودن.
- پروژه‌ها: نوار پیشرفت هر پروژه.
- تنظیمات: چهار سبک طراحی با تغییر زنده، نام نمایشی، مدت تمرکز و استراحت،
  کلید دادهٔ نمونه و خروج با تأیید.

## نکات طراحی

- همهٔ متن‌ها فارسی و چیدمان راست‌به‌چپ است (در ریشهٔ اپ تنظیم شده).
- اعداد با ارقام فارسی نشان داده می‌شوند.
- آیکون‌ها فقط SF Symbols هستند؛ ایموجی استفاده نشده است.
- فونت سیستم iOS استفاده شده؛ اگر خواستی وزیرمتن اضافه شود، فایل‌های فونت
  را به پروژه اضافه کن و در `Theme.swift` به‌جای وزن‌های سیستمی بنشان.

## کارهای باقی‌مانده (هنوز ساخته نشده)

- endpointهای موبایل روی سرور وصله (قرارداد در `API-CONTRACT.md`)
- اعلان‌های پوش (Push Notifications)
- همگام‌سازی آفلاین (Offline Sync)
- آیکون اپ و صفحهٔ شروع (Launch Screen)
- انتشار در App Store
